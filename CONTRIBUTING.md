# Contributing

Thank you for your interest in contributing to `@crowdstrike/strands-aidr`!

## Development setup

```bash
git clone https://github.com/CrowdStrike/aidr-strands-typescript
cd aidr-strands-typescript
npm install
```

## Running checks

```bash
# Type check
npm run typecheck

# Unit tests
npm test

# Build
npm run build
```

All checks must pass before submitting a pull request.

## Pull requests

- Keep changes focused — one logical change per PR.
- Add or update tests for any new behavior.
- Update the README if you change the public API or add configuration options.
- Use clear, descriptive commit messages.

## Reporting issues

Open an issue on [GitHub](https://github.com/CrowdStrike/aidr-strands-typescript/issues) with steps to reproduce, expected behavior, and actual behavior.
